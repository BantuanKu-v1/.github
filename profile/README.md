# BantuanKu
**BantuanKu** is a Final Year Project (FYP) aimed at improving government aid discovery, eligibility recommendations and application assistance for **B40 elderly communities in Kuala Lumpur, Malaysia**.

The project consists of three repositories:

## Repositories
| Repository | Description |
|------------|-------------|
| **fyp-bantuanku** | React Native mobile application for discovering government assistance, checking potential eligibility, and preparing applications. |
| **str-mock-web** | Mock Sumbangan Tunai Rahmah (STR) portal with REST APIs for simulating government aid applications. |
| **bwe-mock-web** | Mock Bantuan Warga Emas (BWE) portal with REST APIs for simulating elderly assistance applications. |

## Disclaimer
This is an academic project developed for educational and research purposes. The mock portals are not affiliated with any Malaysian government agency, and simulated applications are not submitted to official government systems.
